# Archive

Planning documents whose work is finished. They are kept for history and for the
links that test-run reports and manuals still use; they are **not** current
specifications. The authoritative behavior is in [`spec files/`](../../spec%20files/).

- [`issues/`](issues/README.md): the 25 planned development issues from the Nagios Core gap plan.
- [`plans/`](plans/README.md): design and implementation plans for features that have shipped.

Active planning documents stay in [`../plans/`](../plans/).
