## Deviations from the plan

- The deploy copied the whole branch, so the appliance also received everything merged to `main` since its old install, and two more migrations ran (interfaces, recipients). `flask sync-permissions` also added `system.hosts.alerts` and `system.recheck`.
- The Migrations section of `Data_Model_and_Integrations.md` lists `flask db upgrade --multidb`; this appliance's Flask-Migrate rejects that flag, and plain `flask db upgrade` migrated both databases.
- The test host had notifications and active checks switched off for the run, then back on. It is UP again.
