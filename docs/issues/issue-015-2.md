### Issue #15.2 — Web-Interface Refinement Add Guided Process Check Entry to Plugin Settings

**Category:** Web-Interface

**Work Type:** Refinement

**Priority:** Low

**Estimated Complexity:** Low

**Related Nagios Core Feature:** Process Monitoring

**Dependencies:** [Issue #15.1](issue-015-1.md)

**Plan reference:** Issue #15 in [`docs/NAGIOS_CORE_FEATURE_GAP_PLAN.md`](../NAGIOS_CORE_FEATURE_GAP_PLAN.md) §3; this is a sub-issue of Issue #15. The number is a plan identifier, not a GitHub issue number.

#### A. Problem Description

Checking that a process is running needs an administrator to hand-write an NCPA path and query arguments in the metric table. There is no guided form.

#### B. Current Implementation

Paths below were verified in the repository on 2026-10-13 unless marked *(proposed)*.

- `client/src/components/settings/PluginSettings.tsx` edits the NCPA metric table (metric, path, warning, critical, units, query args) with validation mirroring the server.
- `client/src/lib/pluginSettingsApi.ts`, `client/src/types/pluginSettings.ts`; test `client/src/test/PluginSettings.test.tsx`.

#### C. Required Changes

**Frontend / Web Interface**

1. Add an "Add process check" action to the NCPA table that asks for a process name and expected count, and fills the metric name, path and query arguments with the pattern documented in Issue #15.1.
2. Show the generated row for review before saving and keep all existing validation.
